## Local Development

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hafsamaryam08/Portfolio.git
   ```
2. **Navigate to directory:**
   ```bash
   cd Portfolio
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
